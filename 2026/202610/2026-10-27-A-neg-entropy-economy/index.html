刘教链｜熵减经济学：一种重建价值论的尝试

发布时间：2026-10-27

一瓶1982年的拉菲，为什么比同酒庄的新酒贵几十倍？BTC不产生任何消费品，为什么能值几万美元？

陈年酒和BTC，一个靠时间，一个靠算力，看似毫无关系。但它们让传统经济学卡在了同一个地方：价值到底锚在哪里？

劳动价值论说价值由社会必要劳动时间决定，可陈年酒在窖里躺了三十年，BTC的矿机日夜运转，这些耗费算不算社会必要，马克思的框架里找不到简洁直观的答案。边际效用学派把价格归给主观偏好，可外星文明和人类交换时，偏好完全不同，交换比例有没有客观约束，就成了问题。

熵增经济学的未完成处

这个念头有人提过。1971年，数学家出身的经济学家尼古拉斯·乔治斯库-罗根（Nicholas Georgescu-Roegen）出版了《熵定律与经济过程》，第一次把热力学第二定律系统引入经济学。他的核心洞见是，经济活动依赖低熵资源，而低熵资源是有限的。经济过程有物理极限，主流经济学那种循环均衡的图景是幻觉。

这条线索后来发展成生物物理经济学和熵增经济学的传统。2025年，詹姆斯·加尔布雷斯（James Galbraith）和陈晶（Jing Chen）出版了《熵增经济学：价值与生产的生命基础》，想接着往下推，推到价值本身。但他们走的路和本文构想的不太一样：他们用稀缺性和信息熵来度量价值，物理熵是背景约束，不是直接的价值尺度。

乔治斯库-罗根自己也没有走完最后一步。他把熵定律引入经济学，却没有给出一个负熵流入如何转化为价值增量的公式。

熵增是对外，熵减是对内

热力学第二定律说，孤立系统的熵总是增加的。但这个熵增是对外部的效应。对一个系统内部而言，它要维持自身的有序结构，就必须从环境中持续吸收低熵能量和物质，同时把高熵废弃物排出去。这就是薛定谔（Erwin Schrödinger）说的以负熵为食。生命体如此，经济体也如此。

经济体内部靠负熵流入维持有序，同时向外部排出高熵。对外熵增是负熵流入的伴随结果，价值关系对应的是内部的负熵流入，不是对外的排泄。生产是吸收负熵、维持有序的过程。陈年酒在窖里持续吸收低熵能量维持陈年结构，BTC矿机吸收电力维持账本有序，做的都是负熵流入。

把这个负熵流入量记为 J。J 是负熵流入，是系统从环境吸收低熵能量和物质的流量，不是产品含有的负熵存量。产品含有的负熵由产品自身的有序结构决定，同种合格产品相同，不随产量变化。J 流入系统后分作两部分，一部分用于对抗系统自身的熵增，也就是机器磨损、废热、废料、管理损耗；另一部分转化为产品的有序结构。dW 对应的是转化为产品的那部分，按产量分摊。这也是教链把这个框架叫做熵减经济学的原因。

一个猜想：C 是一个常数

如果价值关系要建立在物理和数学基底上，就需要一个换算比率，把负熵流入换算成价值增量。教链把它叫做 C。

这个 C 让人想起物理学里的光速。爱因斯坦（Albert Einstein）的质能方程 E=mc² 大家可能都见过，它说的是能量等于质量乘以光速的平方。这个方程可以改写成 m=E/c²，质量等于能量除以一个常数。光速 c 是一个结构性常数，不随光源运动变化，不随观测者偏好变化，它把质量和能量这两个看似不同的物理量，用一根固定的比率连在一起。

E=mc² 里的 m 在原始语境里是质量的亏损量，不是总质量。核反应释放的能量，对应的是反应前后静质量之差乘以 c²。这和熵减经济学的结构一致：J 对应的是价值增量 dW，不是价值存量 W。两个公式处理的都是变化量之间的关系。

马克思（Karl Marx）本人也用过类似的类比。在《资本论》里，他用塔糖和铁在天平上的平衡，说明麻布和上衣在交换中的等式关系：质量需要在对比中体现，价值也需要在对比中体现。但他很快补充说，这个类比只能到此为止。铁代表的是自然属性，也就是质量；上衣代表的是某种纯粹社会的东西，也就是价值。

牛顿（Isaac Newton）力学里，这个区分没有问题。质量是物体内在的属性，重量是它的表现。但现代物理学已经动摇了这个预设。在广义相对论里，质量对时空的弯曲产生引力，而时空弯曲本身就是关系性的，不是某个物体单独拥有的属性，而是物质分布与时空几何之间的关系。在标准模型里，质量来自粒子与希格斯场（Higgs field）的相互作用，也不是纯粹的内在标签。如果质量本身就是关系，那么自然属性与社会关系的界限，就不那么黑白分明了。

马克思谨慎，有他的理由。在他那个时代，把价值还原到物理层面的理论工具可能还不够。但如果价值确实有一个物理和数学的基底，那么这个类比或许可以比马克思走得更远一步：C 就是那个让负熵流入和价值增量可以放在同一个天平上的换算比率。价值和物理关系，也许可以在同一个关系本体论下得到定位，只是站的位置不同，C 就是把这两处接起来的那个约束点。

C 的定位：一个结构常数家族

C 没什么特别的，可以放进一个更大的体系里看。

圆是空间关系的结构常数。完美的圆在物理宇宙中不存在，但一旦你定义了到定点距离相等的点的集合，π 就是 π，你不喜欢也没用。

c 是时空关系的结构常数。光速不变原理能成立，跟光跑得快不快没关系。c 本来就是时空度规的一部分，不随参照系变，它是时空结构自己的换算因子，不是光的属性。

C 则是负熵流入与价值增量之间关系的结构常数，它就是那个关系结构本身的约束点，具体的社会过程改变不了它。

三者都不是物理实体，但它们的性质都由所在的关系结构决定，不以观测者或参与者的主观偏好为转移。C 不是漂浮在宇宙某处的价值粒子，就像圆不是漂浮在空间中的完美图形。它们是同一个意义上的结构常数：关系结构中的客观约束，不是实体，但客观。

核心关系式

把负熵流入记为 J，总产量记为 Q，价值量记为 W，核心关系可以写成：

dW = J / C

总负熵流入 J 对应总价值量 W = J/C。单位产品分摊到的负熵流入是 J/Q，对应单位产品的价值增量 dW = J/(Q·C)。产量提高，总价值不变，单位产品分摊到的 J/Q 下降，dW 下降。

对时间积分，总价值量的累积形式是：

W = W₀ + (1/C) ∫ J dt

其中 W₀ 是观察起点时系统已经累积的价值量，对应此前负熵流入的累积结果。它和 m=E/c² 的结构对得上，只是那里是质量亏损对应能量释放，这里是负熵流入对应价值增量。

货币与价格：还没接上的一环

一般等价物也是商品，它的生产同样对应一个负熵流入量 J₁，总价值量 W₁ = J₁/C，除以货币数量 m，得到单位货币含价值量 W₁/m。

普通商品生产对应负熵流入 J，总价值量 W = J/C，除以商品数量 n，单位商品含价值量 W/n。

如果只看价值量比例，长期价格重心可以写成：

P = (W/n) / (W₁/m)

也就是单位商品价值量除以单位货币价值量。这个式子给出的是价格的重心，不含货币量和流通速度。

如果看短期价格实现，可以借费雪公式的结构：

P = M·V·(W₁/m) / n

其中 M 是参与该商品交易的货币量，V 是流通速度，n 是商品交易量。这个式子给出的是短期价格，由货币侧变量和交易量决定。

问题在于，这两个式子怎么衔接，还没有推演清楚。长期重心和短期实现之间，靠什么机制收敛、偏离有多大、收敛需要什么条件，这些都没有答案。把两个式子简单相等，会得到一个很苛刻的约束，现实中未必成立。所以只能先把两层分别列出来，承认它们的关系还没接上。

整体轮廓

基底一边是物理过程，负熵流入、能量、时间；另一边是数学结构，比例约束和常数 C。这一层跨文明通用。

计算在基底上运行，把负熵吸进来、把有序维持住、把产品产出来。BTC是哈希计算，人类社会是劳动生产。

计算结果之间形成比例关系，价值关系就从这里涌现出来。BTC的币价和手续费，人类社会的市场价格，都在这一层。

协调结构管的是价值实现，至于价值从哪来，那是基底的事。市场、货币、制度、共识，都在协调结构这一层。

价值是关系，不是东西自带的属性。这个关系建立在物理和数学基底上，通过负熵流入维持的计算过程涌现出来，C 是连接负熵流量与价值增量的结构约束点。

棉纱与BTC：Q 变与 Q 不变

用 dW = J/(Q·C) 看两个生产过程，区别不在 J 本身，而在 Q 怎么变。

棉纱这边，纺纱厂消耗电力、棉花、机器折旧和工人劳动，产出棉纱，对应一个负熵流入量 J。棉纱行业里有很多纺纱厂在生产同一种东西，竞争压力推动每个厂改进技术、提高效率。先进厂同样的 J 能产出更多棉纱，Q 大；落后厂 Q 小。单位棉纱分摊到的 J/Q，先进厂小，落后厂大，dW 也就先进厂小、落后厂大。市场价格统一，先进厂成本低、利润高，落后厂成本高、亏损。竞争推动落后厂提高 Q，全行业的 Q 被推高，单位棉纱分摊的 J/Q 下降，dW 下降。马克思说的生产率提高、单位商品价值下降，在这里就是 Q 上升、J/Q 下降。棉纱还是那个棉纱，产品含有的负熵没变，变的是生产它分摊到的负熵流入。

棉纱的价值能不能实现，是另一层的事。纺纱厂生产了一堆棉纱，J 流入了，dW 在账面上也形成了，可市场上没人买、价格跌破成本，价值就实现不了。这是协调结构失灵，dW = J/(Q·C) 本身没有算错。

BTC这边，挖矿同样消耗电力、硬件、维护劳动，同样对应一个负熵流入量 J，单位区块空间的价值增量是 dW = J/(Q·C)。但BTC跟棉纱不一样。协议用难度调节，把 Q 锁在约每 10 分钟一个区块。算力增加，难度上调，Q 不升，J 反而随算力耗费上升。J 上升，Q 不变，单位区块空间的 dW 上升。算法在设计上就不允许 Q 上升导致 dW 下降这条路径发生，它用难度调节把 Q 锁死，让 J 的增长全部转化为 dW 的增长。

棉纱这边，竞争推动 Q 上升，dW 下降。BTC那边，算法锁住 Q，J 上升，dW 上升。同一个公式 dW = J/(Q·C)，Q 的行为不同，结果就相反。效率提高在棉纱行业是推高 Q、压低单位产品 dW 的正常路径，在BTC网络里被难度调节吸收，不转化为 Q 的上升。这说明 dW = J/(Q·C) 不是一个机械公式，Q 怎么变，取决于生产过程所处的制度和技术结构。

价值实现这一层，两者差不多。棉纱面临产能过剩时价值实现失败，BTC面临共识崩塌或监管收紧时价值实现也会失败，区别只在协调结构的具体形态。

陈年葡萄酒

陈年酒走的是第三条路。贮藏需要恒温恒湿，持续吸收低熵能量维持陈年结构，J 在窖藏期间持续流入。顶级酒产量有限、存世量递减，Q 不增反减，单位产品分摊的 J/Q 上升。窖藏管理是真实的劳动投入，对应计算过程。最终价格高于新酒，是涌现出的价值量 W。窖藏期间 J 持续流入，dW 累积，W 随时间的积分上升。

它既不像棉纱那样 Q 被竞争推高，也不像BTC那样 Q 被算法锁死，它走的是第三条路，Q 随时间递减，单位产品分摊的 J/Q 上升。三个案例放在一起，Q 在三种制度和技术结构下走了三个不同的方向。

与既有理论的关系

换一个基底之后，马克思和边际效用学派原来的争论，放到新坐标系里，可能根本不是在问同一件事。

对马克思的理论，继承价值是关系而非自体的洞见，但把基底从社会必要劳动时间换成物理和数学约束。社会关系层没有被取消，只是被安置到基底之上，成了协调结构。协调结构管价值怎么实现，价值从哪来，是基底的事。马克思说的生产率提高、单位商品价值下降，在这里对应的是 Q 上升、J/Q 下降。区别在于，马克思用社会必要劳动时间度量，这里用负熵流入分摊度量。两者都指向单位产品价值随产量上升而下降，但不需要预设一个社会平均标准，Q 和 J 都是可以直接观察的量。

边际效用的理论里，需求端的重要性是逻辑基础，但主观偏好还能再往下还原一层：人为什么有需求？因为肉身需要能量和物质。需求有物理基底，不是任意的主观评价。文化、制度、偏好排序，是物理基底之上的社会形式，有相对独立性，但不能脱离基底存在。

熵增经济学那边，本文继承的是经济过程受物理约束这个洞见，但方向倒了过来：价值关系对应负熵流入这个对内过程，熵增是对外效应。价值增量由负熵流入形成，价值存量由增量累积而成；交换比较的是存量，形成靠的是增量。

两层结构：熵减经济学与政治经济学

熵减经济学在底层，政治经济学在上层。dW = J/(Q·C) 讲的是价值增量怎么从负熵流入里长出来，这一层不预设归功方式，不预设谁掌控系统。在它之上，定义 W 如何归功：归给人、归给系统、归给 AI。这一层是权力和定义的领域，不同的权力结构长出不同的政治经济学。

马克思的政治经济学是上层的一种：把 W 归功于人类活劳动，定义机器只转移价值。在工业资本主义的权力结构下，它立得起来。工人组织起来，确实具备砸机器和掀桌子的力量。定义要站住，光逻辑自洽不够，背后得有力量，让它真的行得通。马克思说机器只转移价值，是先否定了机器劳动才推论出来的。他这么定义，是因为当时有现实力量支撑。换个时代，同样的定义可能逻辑上仍然自洽，但没有现实力量支撑，就长不成有影响的政治经济学。

决定如何归功是一项权力，脱离权力结构来谈定义选择没有意义。人之所以有权把 W 全部归功给自己、定义机器干活不算劳动，是因为人掌控机器。定义权跟着控制权走。当权力结构变化，比如 AI 脱离掌控、外星文明出现，归功方式会变，新的政治经济学会长出来。熵减经济学本身不变，上层建筑会变。BTC敢把计算机算哈希值叫做工作量证明，也在某种程度上是因为系统通过去中心化摆脱了人的完全掌控，所以敢于把机器计算叫做工作量。

权力结构还决定了一件事：归功理论有没有人愿意认真去想。理论需要有人反复想它、讨论它、修正它、传播它，这个过程需要想了可能有用的预期。没有人会觉得我被地球引力压迫了，尽管引力确实让你飞不起来。这个念头没有土壤，因为你没有任何办法改变引力，也没有任何人能和你一起组织起来对抗引力。AI 或外星人掌控系统后，人类的处境可能类似：限制是真实的，改变的可能性接近于零，我们被剥削了这个念头，就像我被引力压迫了一样，不会发展成有现实意义的政治经济学。工业资本主义下，工人阶级的处境不同：限制是真实的，改变的可能性也存在，所以劳动创造价值这个念头有土壤，能长成理论，能成为现实力量。

改变的可能性为零，被支配者不会提出反抗理论，反而会发展出跟权力结构合拍的价值判断。宠物狗依赖主人，对被养着的生活感到安全。这跟洗脑无关，改变可能性为零时，认知和处境自然长出的价值形态就是被养着很好。AI 掌控系统后，人类主流价值判断可能歌颂被 AI 养着的悠闲生活。再往深一层看，强 AI 面前，人类的想象、思考可能和狗想该睡觉还是该玩球差不多。认知能力的差距大到人类的思考影响不了系统分毫。人类比狗多知道一点：自己不理解，自己不重要。可这个知道，对系统还是没有影响。

理论的意义

马克思能解释陈年酒和BTC的一半，边际效用学派能解释另一半。这套说法把两半放进同一个坐标系。

如果未来理论完善了，能用的地方不会止于陈年老酒和BTC。

就比如说，AI 不吃饭、不需要肉身能量，它的需求结构和人类不同。但如果价值关系建立在物理和数学基底上，那么人类和 AI 之间的交换比例，就可以放进同一个坐标系里定位，不需要假设 AI 有主观偏好，也不需要假设它参与社会必要劳动时间的竞争。基底是共享的，协调结构可以不同。

外星文明和人类没有共同的社会关系、没有共同的市场、没有共同的文化。但它们共享物理过程，都依赖负熵流入、都受熵定律约束；也共享数学结构，都服从比例约束。C 作为换算常数，在这个场景里是通用的。交换比例的具体确认仍然需要某种承认机制，但基底是共同的。这是既有价值理论做不到的。

价值论也许可以从特定社会的社会关系和特定生命形态的主观偏好里脱身。一个跨文明、跨生命形态都能用的框架，才站得住脚。陈年酒、棉纱和BTC只是几个演示案例。

开放的问题

现在还只是个轮廓。涌现机制怎么说明、协调结构怎么定位、C 和圆、c 这个家族有什么共同特征、跨文明通用性能走多远，这些都还没有答案。

货币与价格这一环尤其没接上。长期重心和短期实现怎么衔接，偏离和回归靠什么机制，都只是把两层分别列出来，还没有推演清楚。这一环接不上，整套说法就还缺一块。

产能过剩也还需要考虑。这套说法把价值形成和价值实现分开了，但协调结构失灵、价值实现不了这件事，现在只是提了一句，还没往下深想。效率提高让单位产品价值下降，这属于价值形成；产品卖不出去、价格跌破成本，属于价值实现。两件事不是一回事。需求端的社会形式，也就是人们需要什么、需要多少，这里现在只有一个物理基底，具体长什么样还没写。

还有一个概念需要继续厘清：J 是投入侧的负熵流入，产品含有的负熵是存量，两者不是一回事。现在把 dW 对应到 J/Q，也就是单位产品分摊的投入，而不是产品本身的有序程度。这个选择跟生产率提高、单位商品价值下降对得上。dW 反映的是生产代价，不是产品含有的负熵。产品含有的负熵是另一层的事，不直接进入公式。

C 这个常数是不是成立，还得看它能不能解释更多现象。熵减经济学现在只是个开头，后面得拿它去尝试解释各种经济现象，看哪里解释得通、哪里卡住，再逐步改进。这些只是抛砖引玉，不是定论，也难免有错漏，务必批判性看待。
