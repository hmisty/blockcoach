刘教链｜手搓了一个冷钱包 BTC 地址计算器

发布时间：2026-06-21

过去几年小白课授课一直在用的离线 BTC 冷钱包生成工具 bitaddress.org 是经典，但只支持 P2PKH（1 开头的老地址），不支持现在钱包普遍用的 Native SegWit（bc1q）。而且它只导出裸私钥 WIF，不生成助记词。

读了 BIP-361 的量子迁移方案后更确信了：Phase C 计划用零知识证明 BIP-39 助记词所有权来恢复冻结资金——将来助记词才是证明地址所有权的关键凭证，光有私钥不够。所以决定自己写一个生成器，支持安全随机数和脑钱包两种方式。

用 opencode 从零开搞，大概断断续续花了一周多的时间，成品如下：

bitcalc — 离线比特币地址计算器

  • ✅ 两种熵源：脑钱包（SHA256ⁿ/密码，可选 PBKDF2 迭代） 或 安全随机数（鼠标 + 键盘收集熵，ArcFour PRNG）
  • ✅ Legacy 路径：P2PKH（非压缩公钥）+ Native SegWit（压缩公钥），带 QR 码
  • ✅ 助记词路径：BIP39 12/24 词 → PBKDF2 → BIP32 HD → m/84'/0'/0'/0/{0..9}
  • ✅ 助记词恢复：输入助记词还原种子和 HD 地址列表（10 个）
  • ✅ 验证：校验助记词、私钥 WIF、地址格式
  • ✅ 中英双语：一键切换 UI
  • ✅ 完全离线：grunt 合并为单 HTML，浏览器直接打开，不联网

技术栈：复用 bitaddress.org 的 CryptoJS / secp256k1 / BigInteger 等核心库，手写了 SHA-512、Bech32 编码、BIP39 助记词引擎和 BIP32 HD 钱包派生。无运行时依赖，纯前端。

核心测试向量全部通过（复用 brainwallet.js 的已知数据），密码 "test" 生成的 24 词助记词和 BIP84 地址与标准实现完全一致。
